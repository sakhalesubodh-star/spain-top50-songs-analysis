# Executive Summary

## Project Title
Content Maturity, Release Lifecycle & Playlist Rotation Analysis of Spain Top 50 Songs

## 1. Introduction

Music streaming playlists provide a useful way to study song visibility and
changes in music consumption trends. This project analyzes observations from
the Spain Top 50 playlist to understand song lifecycle patterns, chart
performance, and playlist rotation.

The project uses Python-based data analysis and an interactive dashboard to
present lifecycle metrics and changes between observed playlist snapshots.

## 2. Business Objective

The primary objective is to examine how songs perform during their observed
presence in the playlist and how the playlist composition changes over time.

The analysis focuses on song longevity, peak chart position, time to peak,
new entries, disappearances, and track retention.

## 3. Tools and Technologies

The project uses Python, Pandas, NumPy, Plotly, Streamlit, and Jupyter Notebook.
Visual Studio Code is used to develop and run the interactive dashboard.

## 4. Methodology

The project follows these stages:

1. Inspecting and validating the source dataset.
2. Cleaning data and preparing date fields.
3. Conducting exploratory data analysis.
4. Calculating song lifecycle metrics.
5. Classifying songs into lifecycle stages.
6. Comparing consecutive playlist snapshots.
7. Developing an interactive dashboard.
8. Preparing documentation and final deliverables.

## 5. Key Analytical Measures

The analysis includes the number of observed appearances, first and last
observed dates, best recorded chart position, calendar span, and time to peak.

Playlist rotation analysis includes new entries, disappearances, retained
tracks, retention rate, and exit rate.

The dashboard also provides filters, summary metrics, visualizations, and
downloadable CSV files.

## 6. Business Significance

The project demonstrates how playlist data can be transformed into
understandable analytical outputs.

The results can help analysts explore observed song longevity, identify
patterns in playlist turnover, and compare song lifecycle characteristics.

These insights can support further investigation into playlist performance,
but the analysis alone cannot establish why individual songs become popular
or leave the playlist.

## 7. Limitations

The findings depend on the available observations and the frequency of
playlist snapshots. The first and last observed appearances do not necessarily
represent the actual dates on which a song entered or left Spotify's playlist.

Lifecycle classifications also depend on the thresholds defined in the
analysis.

## 8. Conclusion

This project combines data preparation, exploratory analysis, lifecycle
measurement, playlist churn analysis, and interactive visualization in a
single analytical workflow.

It demonstrates practical skills in Python, data analysis, data
visualization, and dashboard development.

The final conclusions should be supported by numerical results from the
completed analysis rather than assumptions.
